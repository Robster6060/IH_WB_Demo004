# HUD Readout Canon (PIE)

How to read the World Builder HUD from screen grabs:

| Marker | UI location | Meaning |
|--------|-------------|---------|
| **Realm Seed** (red) | Top-left **Realm Seed** text box | Canonical `AAAAA#` seed (5 letters + digit 2–7). Examples: `ABBEY3`, `POKED3`, `ALERT4`, `JUNKS5`, `MAILS6`, `GIZMO7`. |
| **Island count** (orange) | Status line under seed (“N islands”) | Count = **last digit** of the seed. Must match Island Nav row count after regen. |
| **ASL** (green) | Top-right **ASL** box | **Camera** altitude above sea level (fly pawn), **not** island summit height. |

Island Nav **Shape** column (Low / High / Volc) + **Acres** are the authority for topography profile and size when tuning summit H/D ratios.
